# Fruite - Dynamic Fruit Beverage Landing Page

An eye-catching, high-impact marketing landing page for a fruit beverage brand. Features dynamic background color theme-switching corresponding to selected flavor variants (Strawberry, Orange, Green Apple).

##  Features

* **Dynamic Flavor Themes:** Color-coordinated hero sections that adapt background gradients to match the product (Pink, Orange, Light Green).
* **3D Visual Presentation:** Floating fruit particle design accents surrounding central product packaging renders.
* **Product Packaging Assets:** Custom vector label designs included for print/digital rendering.
* **Minimalist E-Commerce Nav:** Clean header menu with quick links (Home, Shop, Contact) and variant selectors.

##  Tech & Design Stack

* **Design Tool:** Figma / Illustrator (3D Mockups)
* **Interactive Tech Stack:** Vue.js / React with GSAP / Three.js (for animated transitions)
